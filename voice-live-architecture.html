Azure Voice Live API — Architecture

Speech-to-speech, hybrid and cascaded voice agents with delegation to any model family

September 2026

The chart reads top to bottom. First, user scenarios: Contact Center, In-car Assistant, Education and Learning, Public Services, HR and Employee Productivity, and Personal Assistant. Second, the client interface: the SDK (Python, C#, JavaScript, Java), WebSocket, WebRTC and SIP exchange audio with the platform, and a photo or video avatar is the visual output. Third, the Azure Voice Live API platform, providing Noise Suppression, Echo Cancellation, Barge-in, Function Calling and Interim Responses, with Enterprise Governance pillars hosting, scalability, safety and observability. Inside the platform are four voice-agent lanes. Full Duplex: GPT-Live-1 handles turn-taking natively and flows straight to Task Delegation; it is marked as coming soon. The Speech to Speech, Hybrid and Cascade lanes each start at a shared Smart Turn-detection stage (semantic voice activity detection and end-of-utterance), then run their model pipeline and flow to Task Delegation. The Hybrid and Cascade lanes share one Azure Speech TTS stage offering HD Voice, Custom Voice, Personal Voice and Marketplace voices. All lanes delegate reasoning and tools; delegation targets are Foundry Agent, GPT, Claude, Gemini, open-source models such as Phi and Llama, and bring-your-own backends or tools. Tags on the segments name the provider: Foundry models or Azure Speech services.
